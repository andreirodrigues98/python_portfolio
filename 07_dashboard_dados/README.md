# 📊 Projeto 07 — Dashboard de Vendas

Aplicação desenvolvida em Python para analisar dados de vendas, gerar indicadores, criar um relatório em TXT e produzir um gráfico com o total vendido por categoria.

---

## 🚀 Funcionalidades

- Cálculo do total vendido
- Cálculo da quantidade de vendas
- Cálculo da média por venda
- Identificação do produto com maior venda
- Identificação do produto com menor venda
- Agrupamento dos valores por categoria
- Geração automática de relatório em TXT
- Geração de gráfico de barras
- Salvamento do gráfico em formato PNG

---

## 📊 Indicadores gerados

O programa apresenta os seguintes indicadores:

- Quantidade de vendas
- Total vendido
- Média por venda
- Maior valor de venda
- Menor valor de venda
- Produto com maior venda
- Produto com menor venda
- Total vendido por categoria

---

## 🛠 Tecnologias utilizadas

- Python 3
- Matplotlib

Também foram praticados conceitos da biblioteca padrão do Python, como manipulação de listas, dicionários e arquivos TXT.

## ⚙️ Instalação

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/python-portfolio.git
```

Entre na pasta do projeto:

```bash
cd python-portfolio/07_dashboard_vendas
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

---

## ▶️ Como executar

Execute o arquivo principal:

```bash
python dashboard_dados.py
```

Após a execução, o programa criará os arquivos:

```text
dashboard.png
relatorio_vendas.txt
```

---

## 📈 Gráfico gerado

O gráfico apresenta o total vendido em cada categoria.

Exemplo de categorias analisadas:

- Informática
- Papelaria

O resultado é salvo automaticamente no arquivo:

```text
dashboard.png
```

---

## 📄 Relatório gerado

O programa também cria um relatório chamado:

```text
relatorio_vendas.txt
```

O relatório contém:

- quantidade de vendas;
- total vendido;
- média por venda;
- produto com maior venda;
- produto com menor venda;
- respectivos valores.
