# 📊 Projeto 05 — Automação de Planilhas

Sistema desenvolvido em Python para criar planilhas do Excel de forma dinâmica, gerar relatórios automáticos e produzir resumos com base nos dados informados pelo usuário.

---

## 🚀 Funcionalidades

- ✅ Criação automática de planilhas Excel
- ✅ Definição dinâmica de colunas e linhas
- ✅ Geração automática da aba **Relatório**
- ✅ Formatação automática do relatório
- ✅ Congelamento da primeira linha
- ✅ Ajuste da largura das colunas
- ✅ Criação automática da aba **Resumo**
- ✅ Contagem de valores por coluna escolhida pelo usuário

---

## 🛠 Tecnologias utilizadas

- Python 3
- openpyxl
