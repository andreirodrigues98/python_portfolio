# 📈 Projeto 06 — Analisador de Planilhas

Aplicação desenvolvida em Python para analisar dados numéricos de planilhas do Excel, gerando estatísticas e um relatório automático em arquivo TXT.

---

## 🚀 Funcionalidades

- ✅ Leitura de planilhas Excel (.xlsx)
- ✅ Seleção dinâmica da aba
- ✅ Escolha da coluna a ser analisada
- ✅ Cálculo automático de:
  - Quantidade de valores
  - Soma
  - Média
  - Maior valor
  - Menor valor
- ✅ Geração automática de relatório em arquivo TXT

---
