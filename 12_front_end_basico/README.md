# Projeto 14 — Automação de Preenchimento de Formulário

Este projeto demonstra uma automação em Python capaz de ler dados de uma planilha e preencher automaticamente um formulário em uma página web.

O objetivo principal é praticar automação de tarefas repetitivas, leitura de planilhas, validação de dados e interação com páginas web.

---

## Aviso sobre o front-end

O front-end utilizado neste projeto é básico e foi criado apenas para fins de teste e demonstração.

A tela de login aceita qualquer usuário e qualquer senha.
