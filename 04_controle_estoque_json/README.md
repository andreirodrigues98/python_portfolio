# 📦 Controle de Estoque com JSON

Sistema de gerenciamento de estoque desenvolvido em Python, utilizando arquivos JSON para persistência dos dados.

O projeto permite cadastrar, consultar, atualizar e listar produtos diretamente pelo terminal.

---

## 🚀 Funcionalidades

- ✅ Cadastro de produtos
- ✅ Listagem de produtos
- ✅ Busca por nome (busca parcial)
- ✅ Atualização da quantidade em estoque
- ✅ Cálculo automático do valor de cada produto em estoque
- ✅ Cálculo do valor total do estoque
- ✅ Persistência dos dados em arquivo JSON

---

## 🛠 Tecnologias utilizadas

- Python 3
- pathlib
- json

Todas as bibliotecas utilizadas pertencem à biblioteca padrão do Python.

## ▶ Como executar

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/python-portfolio.git
```

Entre na pasta:

```bash
cd python-portfolio/04_controle_estoque_json
```

Execute:

```bash
python controle_estoque.py
```
