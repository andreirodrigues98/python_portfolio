# 📂 Conversor de Arquivos

Projeto desenvolvido em Python para converter arquivos entre diferentes formatos de forma simples e rápida.

---

## 🚀 Funcionalidades

Atualmente o sistema permite:

- ✅ Converter CSV → TXT
- ✅ Converter CSV → JSON
- ✅ Converter JSON → CSV

O programa possui um menu interativo no terminal para selecionar a conversão desejada.

---

## 🛠 Tecnologias utilizadas

- Python 3
- pathlib
- csv
- json

Todas as bibliotecas utilizadas fazem parte da biblioteca padrão do Python.
