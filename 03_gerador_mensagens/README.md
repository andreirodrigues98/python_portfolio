# 📱 Gerador de Mensagens

Projeto desenvolvido em Python para gerar mensagens profissionais de forma rápida e padronizada para clientes.

---

## 🚀 Funcionalidades

O sistema permite gerar automaticamente mensagens para:

- ✅ Cobrança
- ✅ Orçamento
- ✅ Agendamento

Além disso, possui:

- 📄 Histórico das mensagens geradas
- 💾 Opção para salvar mensagens em arquivos `.txt`
- 🕒 Saudação automática de acordo com o horário (Bom dia, Boa tarde ou Boa noite)

---

## 🛠 Tecnologias utilizadas

- Python 3
- pathlib
- datetime

Bibliotecas utilizadas apenas da biblioteca padrão do Python.
