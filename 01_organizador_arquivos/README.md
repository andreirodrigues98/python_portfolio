📁 Organizador de Arquivos

Projeto em Python que organiza automaticamente arquivos por categoria.

Tecnologias:

- pathlib
- shutil

Funcionalidades

✔ Organiza PDFs
✔ Organiza imagens
✔ Organiza vídeos
✔ Organiza códigos
✔ Organiza planilhas
✔ Evita sobrescrever arquivos
✔ Relatório final

Como executar

python organizador_arquivos.py
